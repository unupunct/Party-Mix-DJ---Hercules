# Hercules Console DJ 1.0.0

First release: the Party Mix DJ software, rebuilt for the **Hercules DJ Console** (original, Windows Edition, USB `06F8:B000`).

- The console is read as a HID device (WebHID): 30 buttons, EQ pots, volume knobs, pitch faders, crossfader, two jog wheels and the joystick (it drives the DJ filter). No MIDI is involved.
- The screen is drawn after the console: silver plate, black body, studded jog pads with the HARMONIC MATCH hub in the centre, pad buttons 3 2 1 with the FX / CUE / LOOP lights, pitch faders, joystick, crossfader.
- A calibration wizard learns all 42 controls one by one (every control is highlighted on the screen), English or Romanian.
- Everything else of Party Mix DJ is included: native Rust audio engine, colour waveforms, Harmonic Match, Auto DJ, loop control and slicer, XY multi-FX pad, 36 pad effects, visuals, folder browser, M3U / radio.

Files: `HerculesConsoleDJ-Setup-1.0.0.exe` (Windows installer), `HerculesConsoleDJ-1.0.0-portable.exe` (Windows, no install), and the macOS `.dmg` files (Apple silicon and Intel).

Not verified on hardware yet: which LED bit lights which lamp (the unit accepts the LED report), the pitch-fader direction (calibration learns it), and the macOS build with a real console.
